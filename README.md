# Motion Detector (Детектор движения на C++)

Это консольно-графическое приложение на C++ с использованием библиотеки компьютерного зрения OpenCV. Программа захватывает видеопоток с веб-камеры, анализирует соседние кадры и обнаруживает движение. Движущиеся объекты обводятся зеленой рамкой, а время обнаружения записывается в лог-файл `motion_log.txt`.

## Алгоритм:
1. Захватывает текущий кадр с камеры.
2. Кадр переводится в оттенки серого (чёрно-белый формат) и слегка размывается фильтром Гаусса, чтобы убрать цифровой шум матрицы.
3. Вычисляется абсолютная разница пикселей между текущим и предыдущим кадром.
4. К полученной разнице применяется пороговое значение, чтобы отсечь мелкие тени и блики.
5. Ищутся контуры оставшихся пятен. Если площадь контура достаточно большая, считается, что найдено движение.

## Требования для сборки
* Компилятор C++ (с поддержкой C++11)
* Сборочная система CMake (версия 3.10 и выше)
* Установленная библиотека OpenCV (в Linux ставится через `sudo apt install libopencv-dev`)

## Как собрать и запустить

1. Склонируйте репозиторий:
   ```bash
   git clone <ваш-url-репозитория>
   cd motion-detector
   ```

2. Создайте папку для временных файлов сборки и перейдите в нее:
   ```bash
   mkdir build
   cd build
   ```

3. Сгенерируйте Makefile с помощью CMake:
   ```bash
   cmake ..
   ```

4. Соберите проект:
   ```bash
   make
   ```

5. Запустите программу:
   ```bash
   ./MotionDetector
   ```

## Управление
* Нажмите клавишу **`q`** (в английской раскладке), находясь в окне с видео, чтобы корректно завершить работу программы.
